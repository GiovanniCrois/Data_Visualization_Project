Tercera entrega del proyecto final para la materia de Visualización de datos 

Para poder ver las visualizaciones echas para el proyecto se requiere de dos cosas

Python para las visualizaciones "EDA"
Servidor Web (Local) para las visualizaciones mejoradas


-EDA 
  Ejecutar el archivo "visualizaciones_preeliminares.py" con un entorno de Python. 
    *Es necesario contar con las librerias listadas en el mismo archivo) 
    
-Visualizaciones mejoradas
  Extraer el proyecto dentro de un servidor web. Tal cual se estructura en el repositorio. No solo la carpeta "visualizaciones_finales". 
  Al entrar a la ruta del servidor montado. Se desplegara un menu sencillo para ver cada una de las visualizaciones mejoradas
